# Unit tests workspace

DataFlex workspace (`unittests.sws`) with the [DFUnit](https://github.com/DataFlex-dev/DFUnit) test application `AppSrc/LibArchiveTests.src`. It tests every external function of `archive.dll`, every wrapper class, `cFilesArchiver` and the ZIP preflight/extraction security checks of `cArchiveReader`. The workspace depends on the local library (`../Library/LibArchive.sws`), so the tests always compile the code in the `Library` folder.

## Structure

- `AppSrc/`: `LibArchiveTests.src` and the fixture packages in `AppSrc/Tests/`.
- `Programs/`: `Config.ws`, the 7 native 64-bit DLLs the tests need beside the executable, and the compiled `LibArchiveTests64.exe`. Test files go to `Programs/TestTemp` and are removed by the tests.
- `Tests/RunArchiveReaderTests.ps1`: generates the ZIP fixtures, builds `AppSrc/LibArchiveTests.src` and runs the whole DFUnit suite.

## Run

The `ZipReader` fixture needs ZIP fixtures generated by the script, so use the script to run the whole suite (`-KeepFixtures` keeps the fixtures and the result XML):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tests\RunArchiveReaderTests.ps1
```

Build and run by hand (the `ZipReader` tests then fail until the fixtures exist):

```
df-cli build -t LibArchiveTests.src unittests.sws
Programs\LibArchiveTests64.exe -c
```

See `../Library/Help/Tests.md` for the command line arguments and the list of fixtures.
